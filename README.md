# Технологии программирования — 2 семестр

Портфолио с учебными лабораторными работами на C++ (СПбПУ, 1 курс, ПИ).

## Структура

- `labs/` — лабораторные работы и курсовой проект (РГР)

## Лабораторные

| Тема | Папка |
|---|---|
| TP1. Структуры данных, потоки, итераторы, алгоритмы | `labs/01-data-struct` |
| TP2. Многоугольники и словарь команд | `labs/02-polygons-commands` |
| TP3 / РГР. Ориентированный граф | `labs/03-oriented-graph` |

### Кратко о работах

- **01-data-struct** — разбор и вывод пользовательской структуры (`ull`, `complex`, `string`) через перегрузки `>>`/`<<`, сортировка и работа с итераторами потоков.
- **02-polygons-commands** — чтение многоугольников из файла, подсчёт площадей/вершин, команды `AREA` / `MAX` / `MIN` / `COUNT` / `ECHO` / `INFRAME`.
- **03-oriented-graph** — класс ориентированного графа: вершины/рёбра, степени, истоки и стоки, удаление кратных рёбер и циклов.

## Как собрать

Однофайловый / малофайловый пример (из папки лабораторной):

```bash
# TP1
g++ -std=c++17 main.cpp DataStruct.cpp OtherStructures.cpp iofmtguard.cpp -o app

# TP2
g++ -std=c++17 main.cpp Commands.cpp Polygon.cpp Point.cpp OtherStructures.cpp iofmtguard.cpp -o app

# TP3 / РГР
g++ -std=c++17 main.cpp Graph.cpp -o app
```

Для TP1 входные данные — в `test.txt`. Для TP2 пример фигур — `figures.txt` (программа запросит имя файла).

## Примечание

В репозиторий включены только мои исходники (`.cpp`, `.h`) и необходимые входные `.txt`.
Отчёты, чужие решения и артефакты сборки Visual Studio не входят.
